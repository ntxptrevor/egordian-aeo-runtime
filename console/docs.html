API & MCP client documentation

Protocol revision 2026-07-28 · stateless · bearer-only

1 · Transport

One endpoint: POST /mcp. JSON-RPC 2.0, one request object per call. There is no initialize handshake, no Mcp-Session-Id, no GET event stream, no batching and no sticky sessions — any replica answers any request.

HeaderRequiredRule
AuthorizationyesBearer token issued by the operator.
MCP-Protocol-VersionyesMust be exactly 2026-07-28.
Mcp-MethodyesMust equal the JSON-RPC body method.
Mcp-NameconditionalMust equal params.name for tools/call and params.uri for resources/read; must be omitted otherwise.
Mcp-Session-IdneverRejected: the server is stateless.

Every request carries client metadata in params._meta.clientInfo. Every response carries serverInfo, and discovery-style responses carry ttlMs and cacheScope.

curl -sS https://HOST/mcp \
  -H "Authorization: Bearer $TOKEN" \
  -H "MCP-Protocol-Version: 2026-07-28" \
  -H "Mcp-Method: tools/call" \
  -H "Mcp-Name: catalogue_search" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"catalogue_search",
                 "arguments":{"handle":"...","project_id":"P-1","query":"chain link fence"},
                 "_meta":{"clientInfo":{"name":"curl","version":"8"}}}}'

3 · Handles, scopes and approvals

Call handle_create once per project to mint an opaque, user-bound, project-bound, expiring handle. Every other tool validates it on every call. Authentication material is never stored in a protocol session.

ScopeGrants
catalogue:readCatalogue info/search/get/browse, crosswalk, lessons.
egordian:readDocumented eGordian GET operations and intake tools.
egordian:writeDocumented PUT/POST operations (still requires the write capability flag).
aeo:runCreate assignments and run stages 0-6 and 8.
aeo:approveDecide the stage 7 human gate and promote learning.
adminImplies every scope; required for admin-classified routes.

Every side-effecting tool requires all three of:

"idempotency_key": "unique-key-per-intent"

4 · Refusals by design

DELETE routes — human_gate_required
Registered from the Help page but never executed. A named human must act directly in eGordian.
GET api/HealthCheck/RefreshCache — admin_operation_disabled
Mutates remote cache state; requires ALLOW_ADMIN_OPERATIONS=true plus the admin scope.
PriceProposalsV1 draft/submit — capability_not_documented
Only GET v1/Owners/{ownerId}/PriceProposals is published. AEO stage 8 therefore stays assisted and emits a submission packet for a human to file.
Catalogue bulk export / download — licensing boundary
No endpoint can dump, page through, or download catalogue content. Result counts are capped and cost fields are redacted without authorization.
